# Anamcara Bodywork

**Built end-to-end with [Cursor](https://cursor.com) and [Stitch](https://stitch.withgoogle.com/) — no hand-wavy demo, a real [Next.js](https://nextjs.org) site that runs.**

This project demonstrates creating a production-shaped frontend using only AI for design and iteration.

Stack: Next.js (bootstrapped with [`create-next-app`](https://nextjs.org/docs/app/api-reference/cli/create-next-app)), standard App Router patterns.

Deployed to: [https://anamcarabodywork.com](https://anamcarabodywork.com)
